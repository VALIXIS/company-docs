# 🔥 Soul Ember: Survivors (Online Edition)

A 2D top-down action roguelite survival game built in high-performance HTML5 Canvas & Web Audio API. 
**Zero dependencies, zero build steps, 100% self-contained in a single file.**

---

## 🎮 Game Features
- **3 Distinct Playable Heroes:**
  - 🧙‍♂️ **Pyromancer:** Fires bursting flame bolts and drops Holy Fire puddles.
  - 🧝‍♀️ **Frost Sorceress:** Casts freezing Frost Novas to slow and shatter swarms.
  - 🥷 **Void Rogue:** Enhanced movement speed with innate Chain Lightning strikes.
- **Permanent Meta-Progression (The Soul Forge):**
  - Collect Gold coins from defeated monsters and treasure chests.
  - Buy permanent account upgrades: *Titan Vitality (HP)*, *Void Might (Damage)*, *Swift Stride (Speed)*, *Astral Magnet (Pickup Radius)*, and *Golden Fortune (Gold Find)*.
  - Auto-saved via browser `localStorage`.
- **Boss Encounter:**
  - **Malakor, Void Lich** descends at 2:00 with an alert banner, dedicated Boss HP Bar, and void skull projectiles.
- **Cross-Platform Controls:**
  - **PC / Keyboard:** `WASD` / Arrow keys to move, `Space` to Dash, `P` to Pause, `F` for Fullscreen.
  - **Mobile / Tablet:** Virtual touch analog joystick + on-screen Dash button.
- **Synthesized Retro Audio Engine:** Multi-track chiptune soundtrack + complete procedural sound effects without external audio files.

## 🚀 How to Launch Online (100% Free)

### Option 1: itch.io (Best for Indie Games & Monetization)
1. Compress your folder or simply zip `index.html` into a file named `game.zip` (make sure `index.html` is at the root of the zip).
2. Go to [itch.io](https://itch.io) and click **Upload New Project**.
3. Set **Kind of project** to: **HTML (You have a ZIP file containing your game)**.
4. Upload your `game.zip` and check the box: **"This file will be played in the browser"**.
5. Set viewport size to `960 x 600`.
6. Click **Save & View Page** — your game is now live and playable by anyone worldwide!

### Option 2: GitHub Pages (Instant Web Link)
1. Create a free repository on [GitHub](https://github.com) named `soul-ember`.
2. Push or upload `index.html`.
3. In repository **Settings** → **Pages**, set branch to `main` and root `/`.
4. Your game will be live at `https://<your-username>.github.io/soul-ember/`!

### Option 3: Netlify / Vercel Drop (30 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the folder containing `index.html`.
3. Netlify immediately generates a fast global HTTPS link you can share with anyone.
