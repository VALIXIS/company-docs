## 🚀 How to Enable GitHub Pages for this Repo

1. Go to **Settings** in `https://github.com/VALIXIS/company-docs`
2. Scroll to the **Pages** section in the left sidebar.
3. Under **Build and deployment** > **Source**:
   - Select **Deploy from a branch**.
   - Branch: **`main`** / Folder: **`/ (root)`**.
4. Click **Save**.
5. Within 60 seconds, your site is live at:  
   `https://valixis.github.io/company-docs/`

*(Optional: You can also connect a custom domain like `portfolio.valixis.com` or `valixis.com` directly in GitHub Pages settings!)*
